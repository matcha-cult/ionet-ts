# @nbb-ionet/demo-codegen

**Phase 4** 代码生成示例 - 展示如何从 Action 定义自动生成多语言客户端代码。

## 功能展示

- **Action 扫描**：自动扫描 `@ActionController` 和 `@ActionMethod` 元数据
- **多语言生成**：支持 TypeScript、C#、GDScript、Lua 四种语言
- **类型安全**：生成的代码包含完整的类型定义
- **命令常量**：自动生成 cmd/subCmd 常量
- **API 方法**：生成类型安全的 API 调用函数

## 运行

```bash
# 从项目根目录运行
pnpm --filter @nbb-ionet/demo-codegen start

# 或进入目录运行
cd demos/demo-codegen
pnpm start
```

## 生成的代码内容

### TypeScript

```typescript
// 命令常量
export const HallCmd = {
  cmd: 1,
  loginVerify: 1,
  hello: 2,
} as const;

// 请求/响应类型
export interface LoginVerifyRequest {
  jwt: string;
}

export interface LoginVerifyResponse {
  id: number;
  nickname: string;
}

// API 方法
export function loginVerify(jwt: string): Promise<LoginVerifyResponse> {
  return sendRequest(HallCmd.cmd, HallCmd.loginVerify, jwt);
}
```

### C#（Unity）

```csharp
namespace Ionet.Generated
{
    public static class HallCmd
    {
        public const int Cmd = 1;
        public const int LoginVerify = 1;
        public const int Hello = 2;
    }

    public class LoginVerifyRequest
    {
        public string Jwt { get; set; }
    }

    public class LoginVerifyResponse
    {
        public int Id { get; set; }
        public string Nickname { get; set; }
    }
}
```

### GDScript（Godot）

```gdscript
class_name HallCmd

const CMD = 1

class LoginVerifyRequest:
    var jwt: String

class LoginVerifyResponse:
    var id: int
    var nickname: String
```

### Lua（OpenResty）

```lua
local HallCmd = {
    cmd = 1,
    loginVerify = 1,
    hello = 2,
}

local LoginVerifyRequest = {}
function LoginVerifyRequest.new(jwt)
    return { jwt = jwt }
end

return HallCmd
```

## 集成到构建流程

### 基本用法

```typescript
import { scanActions, TypeScriptCodeGenerator } from '@nbb-ionet/extension-codegen';
import { writeFileSync } from 'fs';
import { HallAction, ChatAction } from './actions';

// 1. 扫描 Action
const actions = scanActions([HallAction, ChatAction]);

// 2. 生成 TypeScript 代码
const tsGen = new TypeScriptCodeGenerator();
const tsCode = tsGen.generate(actions);
writeFileSync('./client/src/api.ts', tsCode);

// 3. 生成 C# 代码（Unity）
const csGen = new CSharpCodeGenerator();
const csCode = csGen.generate(actions);
writeFileSync('./unity-client/Assets/Generated/Api.cs', csCode);
```

### 构建脚本

在 `package.json` 中添加：

```json
{
  "scripts": {
    "codegen": "tsx scripts/generate-client.ts",
    "build": "pnpm run codegen && tsc"
  }
}
```

### CI/CD 集成

```yaml
# .github/workflows/codegen.yml
name: Code Generation

on:
  push:
    paths:
      - 'packages/core-framework/src/**'
      - 'packages/*/src/actions/**'

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v2
      - run: pnpm install
      - run: pnpm run codegen
      - run: |
          git config user.name github-actions
          git config user.email github-actions@github.com
          git add client/src/api.ts
          git commit -m "chore: update generated client code" || true
          git push
```

## 故障排查

### 扫描不到 Action

**检查**：
1. Action 类是否添加了 `@ActionController(cmd)` 装饰器
2. Action 方法是否添加了 `@ActionMethod(subCmd)` 装饰器
3. 是否导入了 `reflect-metadata`
4. `tsconfig.json` 是否启用了 `emitDecoratorMetadata`

### 类型推断错误

**问题**：某些复杂类型（如联合类型）无法准确映射

**解决**：
- 使用明确的类型标注
- 避免使用联合类型
- 使用接口替代类型别名

### 生成的代码格式不对

**检查**：
- 确保模板字符串的缩进正确
- 使用 Prettier 格式化生成的代码
